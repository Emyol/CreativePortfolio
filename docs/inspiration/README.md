# Inspiration boards

References gathered with the `design-inspiration` skill. **Inputs to decisions, not
decisions.** The theme/World and site shape get settled in brainstorming and the spec.

- One board per brief: `YYYY-MM-DD-<brief>.md`, e.g. `2026-10-14-scroll-storytelling.md`.
- Screenshots go in `shots/`, which is gitignored and local only (other people's work).
- The owner can mark entries **keep** / **drop**. Dropped ones stay so they aren't re-found.

## Board format

```markdown
# <Brief, in one line>

Looking for: <mood / layout / technique / component>, for <which part of the site>.

## <Site or component name>

- Link: <live URL> (via <gallery page>)
- Why it works: <the idea, one or two sentences>
- How it's built: <stack and technique; mark "inferred" where guessed>
- Steal: <the one thing worth taking>
- Avoid: <what would hurt this site, especially accessibility or motion>
- Fit: technique | voice | both
- Motion: watched in browser | **unverified**, owner to watch
- Owner: keep | drop | (blank)
```
